Safety

Built so a slip never costs you a file

  • Preview

    --dry-run shows what would change. Nothing is touched.

  • Confirm

    It asks before deleting. Only --force skips the question.

  • Trash

    Removed files go to the trash. Restore them any time.

  • Stop

    Nobody to answer? It stops instead of guessing.

What it does

Pick a job, copy the command

  • See what is in a folder Just looking

    audio-tools stats ./library

  • Convert to another format Makes copies

    audio-tools convert ./samples --format mp3

  • Even out the volume Makes copies

    audio-tools normalize ./samples

  • Find duplicates Just looking

    audio-tools find-dupes

  • Clear out tiny clips Asks first

    audio-tools remove-short --threshold 2 --dry-run

  • Rename in bulk Renames

    audio-tools rename --pattern '{n}_{orig}' --dry-run

  • Feed other tools Advanced

    audio-tools list --json

  • Prefer a menu? Easiest

    audio-tools

2. Check

source ~/.bashrc && audio-tools --version

FAQ

Quick answers

What is Audio Tools?

Audio Tools is a free, open-source command-line tool for batch converting, normalizing, renaming and de-duplicating audio files. It runs on Linux, macOS and Windows (via WSL) and uses ffmpeg.

Could I lose my files by accident?

It is built to prevent that. Removed files go to the trash, it asks before deleting, and the --dry-run option previews any action without changing a file.

Where do removed files go?

To your system trash: the Trash on macOS, or the trash on Linux and WSL. If none is available, to a to_delete folder next to the files. On WSL this is not the Windows Recycle Bin.

Which audio formats does it support?

It reads WAV, OGG, FLAC, AAC, WMA and M4A, and saves as MP3, WAV, OGG, AAC (M4A) or FLAC.

Does Audio Tools work on Windows?

Yes, through WSL, a free Microsoft feature that runs Linux programs inside Windows. The Windows tab in Install shows the steps.

Do I need to be a programmer?

No. Run audio-tools on its own and pick from a menu, or paste one-line commands.

Is Audio Tools free?

Yes. It is released under the MIT license, with no account and no tracking.
